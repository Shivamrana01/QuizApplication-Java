
# Quiz Application in Java

A simple console-based Quiz Application developed using Java. It asks multiple-choice questions, checks answers, calculates scores, and displays the final percentage.

## Features

- Multiple-choice questions (MCQs)
- Four options for each question
- Automatic answer checking
- Instant feedback for correct and incorrect answers
- Score calculation
- Final percentage display
- Performance message based on score

## Technologies Used

- Java
- Arrays
- Loops
- Conditional Statements
- Scanner Class
- String Handling

## Project Structure

```text
QuizApplication/

```

## How to Run

### 1. Compile the program

```bash
javac QuizApplication.java
```

### 2. Run the program

```bash
java QuizApplication
```

## How It Works

1. The application displays five Java-related questions.
2. Each question has four options.
3. The user enters A, B, C, or D.
4. The program checks the selected answer.
5. At the end, it displays the total score and percentage.
